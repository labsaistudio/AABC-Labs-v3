# Proof Ledger

The proof ledger records:

- prepared transaction records
- generated artifacts
- Solana capability plans
- source package manifests
- public proof feeds

Public feeds are redacted before export. Private payload fields are never
required for local demos.

The static proof export includes the run timeline, prepared transaction records,
generated artifacts, and the source package manifest so a reviewer can inspect a
completed run without using the hosted product.
